County of Marin Micro-App

A durable starter for small County web tools using semantic HTML, Pico.css, County branding, and vanilla JavaScript.

Overview Components Forms Data

Build small County tools without a build step

This codebase demonstrates the County of Marin micro-app structure from SPEC.md. It is intended for local-first utilities, internal review apps, data cleanup workflows, dashboards, and other focused tools that should run from a basic static host or directly from file:///.

Required stack

  • Semantic HTML
  • Pico.css base styles
  • shared/app-brand.css County branding
  • Vanilla JavaScript in app.js
  • Jost heading typography with accessible fallbacks

Accessibility baseline

The shell includes a skip link, one main landmark, visible focus styles, labeled controls, non-color-only status labels, and a light/dark mode toggle aligned with WCAG 2.2 Level AA.

Branding approach

The demo uses the official County logo stored locally in the codebase. Logo artwork should not be recreated, recolored, stretched, or approximated.

County color tokens

Use Marin colors as accents and UI indicators while preserving readable text contrast.

  • Black
  • Gold
  • Blue
  • Green
  • Brown
  • Red

Reusable UI patterns

Info: Use alerts for short contextual messages that do not interrupt the workflow.
Success: Pair status color with clear text so meaning is not color-only.
Warning: Gold is used as an accent with dark text for sufficient contrast.
Error: Use direct language and associate form errors with their controls.
